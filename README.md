# 🌐 Personal Portfolio Website

A modern, responsive, and developer-focused personal portfolio website built to showcase my software development projects, design work, skills, and background. Features a slick single-page layout with a sleek dark theme and smooth navigation.

---

## ✨ Features

- 🧭 **Single-Page Layout:** Sticky navigation bar with smooth scrolling across all sections.
- 🙋 **Hero Section:** Concise introduction, key technical skills, and quick-action links to Email, LinkedIn, and GitHub.
- 🛠️ **Comprehensive Background:** Dedicated sections detailing my Skills, Work Experience, and Academic Education.
- 💼 **Project Showcase:** Highlights featured web and mobile applications with detailed summaries and tech stacks.
- 📄 **In-Page CV Preview:** Modal popup to view my CV directly on-page, alongside an instant download link.
- 📱 **Fully Responsive Design:** Tailored user experience with distinct optimizations for both desktop and mobile layouts.
- 🌙 **Dark Theme Styling:** Built-in dark mode featuring a warm orange accent color palette and a stylized custom scrollbar.

---

## 🚀 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / TypeScript
- **Styling:** CSS Custom Properties (Variables), Responsive Flexbox/Grid
- **Icons & Assets:** Custom SVG / Icon Fonts
